🩹 Reflow v1.0.1 — Consistent CLI and Portable Container Startup

Reflow v1.0.1 is a focused patch release for root-command presentation,
successful informational exits, and production-container portability.

### Fixed

- Running `reflow` without a subcommand now shows the Reflow banner and root
  help, then exits successfully.
- `reflow --help` continues to show the banner by default, while `--no-banner`
  suppresses it consistently.
- `reflow --version` now returns a successful exit status.
- The production image can start from any mounted repository, including
  JavaScript or documentation repositories that do not contain `/workspace/app`.
- Reflow no longer validates a default project-source directory while importing
  its CLI. Operational repository targeting remains unchanged.

### Docker verification

```bash
docker run --rm ghcr.io/devalltect00/reflow:v1.0.1 --help
docker run --rm -v "$PWD:/workspace" -w /workspace \
  ghcr.io/devalltect00/reflow:v1.0.1 --help
```

Mounting a repository does not authorize mutation. Continue to use `--dry-run`
for operational previews and explicitly select the intended repository target.
