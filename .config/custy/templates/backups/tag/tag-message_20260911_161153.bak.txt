🛠️ Reflow v1.0.2 — Cleaner Development Workspaces

Reflow v1.0.2 is a maintenance release that improves repository isolation and
project presentation without changing release operations.

### Highlights

- Ignore supported development, production, publishing, and auxiliary virtual
  environment directories in repository tooling.
- Align Git, Docker, formatter, and linter exclusions.
- Extend regression coverage for container ignore rules.
- Add a portable CLI preview and standardize public project contact metadata.

Repository targeting, tag conversion, release recovery, Docker publishing,
confirmation, and dry-run behavior are unchanged.

### Release information

- Version: `v1.0.2`
- Previous version: `v1.0.1`
- Release type: patch
- Runtime: Python 3.14+
- Stability: stable
