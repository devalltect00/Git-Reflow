### ⚠️ Breaking Changes

#### Reflow

- Configuration moves from `.reflow.toml` to `.config/reflow/config.toml` and uses the new `[tool.reflow.*]` namespaced schema.
- The former top-level `reflow convert-tags` command is replaced by the explicit `reflow tags convert local` and `reflow tags convert remote` scopes.
- The former top-level `reflow replay-tags` workflow is replaced by `reflow releases recover`; `reflow tags replay` remains only as a deprecated compatibility alias.
- Tag conversion no longer uses additive `--push` or `--delete-old` controls. Choose `local` for one local reference transaction or `remote` for one guarded atomic remote replacement after reviewing the plan.
- Operational commands can target a configured local path or remote URL instead of always using the invocation directory.
- The console entrypoint moves from `app.cli:app` to `app.cli.main:main`.
- Internal CLI, core, service, executor, configuration, UI, and extension module paths have changed substantially.
